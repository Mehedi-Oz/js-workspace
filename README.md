# js-workspace

A structured JavaScript learning workspace covering the language fundamentals through browser APIs and async programming, with hands-on practice projects.

## Structure

| Folder | Topics |
|---|---|
| `01-fundamentals` | Variables (`var`/`let`/`const`), data types, operators, control flow, loops, functions, arrays, objects |
| `02-dom-and-events` | DOM traversal and manipulation, event listeners, event phases, the event object |
| `03-forms-and-timers` | Forms, validation, `FormData`, `preventDefault()`, `setTimeout`/`setInterval`, `requestAnimationFrame` |
| `04-browser-storage` | `localStorage`, `sessionStorage`, cookies, JSON serialization |
| `05-core-javascript` | Scope, execution context, closures, `this`, `call`/`apply`/`bind`, OOP & prototypes, callbacks, promises, `async`/`await`, Fetch API, HTTP basics |
| `06-practice-projects` | Four mini apps applying everything above |


## Practice Projects

| Project | Description |
|---|---|
| `call-app` | Contact manager with modal form, regex validation, category color coding, and `sessionStorage` persistence |
| `realtime-search-filter` | Live search filtering over dynamically rendered user cards |
| `thiskeyword` | User-manager app demonstrating correct `this` binding with `.bind()` |
| `toaster` | Configurable toast notification factory with themes, positioning options, and auto-dismiss timers |
